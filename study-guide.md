# Study Guide

Starting LeetCode is genuinely difficult. If you don't know where to begin, I recommend following the [LeetCode 150](https://leetcode.com/studyplan/top-interview-150/).

## Study tips

1. **Visualize the problem.** Draw it out on paper, a whiteboard, whatever works.
2. **Think out loud.** Being able to explain how you solve a problem matters as much as solving it.
3. **Give it 15-20 minutes before looking for help.** If you're still stuck after that, watching a YouTube explanation is a great idea.
4. **Don't worry about optimization yet.** Get a working solution first, then make it faster.
